## 🏗️ What I Focus On

```text
Frontend Application
│
├── Presentation Layer
│   ├── Pages
│   ├── Components
│   └── UI States
│
├── Business Logic Layer
│   ├── Custom Hooks
│   ├── Application Logic
│   └── Data Transformations
│
├── Service Layer
│   ├── API Requests
│   └── External Integrations

    ├── Reusable Components

    └── Constants
```

I aim to separate concerns clearly so applications remain easier to **understand, test, maintain, and scale**.
